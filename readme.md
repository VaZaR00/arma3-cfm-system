# CFM — Camera Feed for Monitors Mod

Welcome to the official documentation for **CFM (Camera Feed for Monitors)** — a multiplayer-ready Arma 3 mod that streams live video feeds from UAVs, vehicles, soldier GoPro helmet cameras, and static CCTV cameras onto 3D monitors, handheld tablets, and onboard vehicle screens.

## Quick Requirements

- **[CBA_A3](https://steamcommunity.com/sharedfiles/filedetails/?id=450814997)** is required.
- **Picture-in-Picture (PiP)** must be enabled in Arma 3 Video Settings (*Options → Video → General → PiP → Low or higher*).
- A **UAV Terminal** must be equipped to use personal **Handheld Tablets** or to take direct UAV control from a monitor.
